# Dream Holidays Accounting Flow

## Principle

Everything begins from a Booking / Trip File. Invoices, client payments, vendor bills, vendor payments and margins are all connected to that booking.

## Flow

1. Create client.
2. Create booking/trip file.
3. Add services: Air Ticket, Hotel, Visa, Tour Package, etc.
4. Select vendor for each service.
5. Enter sale amount and vendor cost.
6. System calculates expected gross margin.
7. Generate client invoice from booking items.
8. Record client payment against invoice.
9. Generate/confirm vendor bill/payable.
10. Record vendor payment.
11. Booking dashboard shows sale, received, cost, paid, margin, receivable and payable.

## Accounting meaning

- Sale amount = what Dream Holidays charges client.
- Vendor cost = what Dream Holidays owes vendor.
- Gross margin = sale amount - vendor cost.
- Receivable = invoice total - client payments.
- Payable = vendor bill total - vendor payments.
- Net cash position = client payments received - vendor payments paid.
